# ml_projects
Учебные проекты по машинному обучению

## [Titanic](./titanic) — классификация

Предсказание выживаемости пассажиров. Сравнение логистической регрессии, дерева решений и случайного леса. Лучший результат: accuracy 0.816 (случайный лес после настройки гиперпараметров).

## [California Housing](./california-housing) — регрессия

Предсказание медианной стоимости жилья по районам Калифорнии. Сравнение линейной регрессии, дерева решений и случайного леса. Лучший результат: R² = 0.805 (случайный лес).
